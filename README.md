# Flask Student Management Dashboard (Capstone)

## Features
- REST APIs for Users, Students, Courses
- SQLite database
- Flask test suite (pytest)

## Setup
```bash
pip install -r requirements.txt
python run.py
```

## Run Tests
```bash
pytest
```

## API Endpoints
- GET /api/users/
- POST /api/users/
- GET /api/students/
- POST /api/students/
- GET /api/courses/
- POST /api/courses/
